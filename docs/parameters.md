# 参数速查 · Parameter reference

所有参数集中在 [js/config.js](../js/config.js)。带滑块的可直接用右侧调试面板实时调整（拖动即刻生效）；不带滑块的只能改 `config.js` 并刷新。

单位约定：**速度 = px/秒，加速度 = px/秒²，时间 = 秒**。画布尺寸 `640 × 448`。

---

## 一、天气循环（7 项）

| 参数 | 默认 | 范围 | 拉到最小 | 拉到最大 |
|---|---|---|---|---|
| `ENABLED` | 开 | 开 / 关 | 关：退回手动静态雪天，`SNOW_COVER.GROUND_HEIGHT` 直接生效 | — |
| `RISE` 上升时长 | 16 | 1–40 | 1：雪瞬间变大，没有渐强过程 | 40：一场漫长的酝酿 |
| `HOLD` 峰值停留 | 6 | 0–20 | 0：A 字变成尖顶，一去就回落 | 20：长时间维持暴雪 |
| `FALL` 下降时长 | 20 | 1–40 | 1：雪突然停 | 40：慢慢减弱 |
| `CLEAR` 晴天时长 | 36 | 0–60 | 0：没有晴天间隔，A 字首尾相接 | 60：漫长的晴天 |
| `PEAK_INTENSITY` 峰值强度倍率 | 1 | 0–2 | 0：即使到峰值也不下雪 | 2：峰值时降雪量翻倍 |
| `PEAK_COVER` 峰值积雪高度 | 1 | 0–1 | 0：峰值也不积雪 | 1：峰值铺满整个画布 |

一个周期 = `RISE + HOLD + FALL + CLEAR`，默认 **78 秒**。

> **注意**：地面堆积速度上限是 `CHANGE_RATE`（默认 0.05/秒）。理论上从 0 堆到满至少需要 **20 秒**，所以 `RISE + HOLD` 低于 20 秒时，峰值积雪永远堆不满。

## 二、雪花粒子（16 项）

| 参数 | 默认 | 范围 | 拉到最小 | 拉到最大 |
|---|---|---|---|---|
| `SPAWN_PER_SECOND` 发射量 | 60 | 0–400 | 0：完全不发射，空中无雪 | 400：同屏约 2200 片，明显掉帧 |
| `GRAVITY` 重力 | 20 | 0–200 | 0：匀速下落，雪花像悬浮 | 200：约 2 秒砸到地面，像冰雹 |
| `FALL_SPEED_MIN` 下落初速（慢） | 30 | 0–200 | 0：出生瞬间不落，先"悬停"再被重力拉走 | 200：初速盖过重力，直线砸落 |
| `FALL_SPEED_MAX` 下落初速（快） | 80 | 0–300 | 同左 | 300：最快 1.45 秒穿屏 |
| `DRIFT_SPEED` 自身飘动 | 25 | 0–100 | 0：横向只受风影响，轨迹整齐 | 100：每片自带 ±100px/s 乱速，左右乱飘 |
| `WIND_BASE` 风力基准 | 20 | −100–100 | −100：持续向左吹 | 100：持续向右吹 |
| `WIND_AMPLITUDE` 风力幅度 | 30 | 0–120 | 0：恒定风，没有"一阵一阵" | 120：风力峰值可达 220px/s，雪几乎横着飞 |
| `WIND_PERIOD` 阵风周期 | 6 | 1–20 | 1：每秒来回摆一次，雪花"摇头"，很假 | 20：几乎察觉不到风在变 |
| `LIFE_MIN` 寿命（短） | 3 | 0.5–10 | 0.5：雪只飘在顶部一小段就消失，落不到地 | 10：短寿命片也能落到底 |
| `LIFE_MAX` 寿命（长） | 8 | 1–20 | 1：所有雪撑不过 1 秒 | 20：同屏雪量按比例涨 |
| `FADE_IN` 淡入时长 | 0.5 | 0–3 | 0：雪突然出现，闪 | 3：出生 3 秒才完全不透明，像雾 |
| `FADE_OUT` 淡出时长 | 1 | 0–3 | 0：到点突然消失，闪 | 3：死前 3 秒一直变淡，整体稀薄 |
| `SHAPE_SCALE` 雪花大小 | 1 | 1–4 | 1：1px 细雪（像素风标准） | 4：每片 20×20px，变成大块马赛克 |
| `BRIGHT_MIN` 雪花最暗亮度 | 0.95 | 0.95–1 | 0.95：雪花亮度随机分布在最暗~纯白之间 | 1：所有雪花纯白，与地面拉开最大差 |
| `FLICKER` 亮度闪烁幅度 | 1 | 0–1 | 0：不闪，雪花亮度固定 | 1：在自身亮度上摆动覆盖整个色阶 |
| `FLICKER_SPEED` 闪烁速度 | 2.5 | 0–10 | 0：不闪 | 10：快速闪烁 |

## 三、积雪（4 项）

| 参数 | 默认 | 范围 | 拉到最小 | 拉到最大 |
|---|---|---|---|---|
| `GROUND_HEIGHT` 积雪高度 | 0.28 | 0–1 | 0：雪线压到画布底，地面露草 | 1：雪线升到画布顶，整屏全白 |
| `CHANGE_RATE` 堆积 / 消融速度 | 0.05 | 0–2 | 0：瞬间到位（关掉堆积动画，雪地紧跟天气） | 2：0.28→0.8 只要 0.26 秒，滞后感消失 |
| `GROUND_JITTER` 雪线抖动 | 14 | 0–60 | 0：雪线是一条水平直线，很假 | 60：±60px 的陡阶梯雪堆 |
| `OBJECT_COVERAGE` 物体覆雪率 | 0.8 | 0–1 | 0：树和小人完全没雪 | 1：所有朝上表面全盖白 |

> `GROUND_HEIGHT` 只在天气循环**关闭**时生效；开启时积雪高度由 `PEAK_COVER × W(t)` 决定。

## 四、面板外参数（改 config.js 后刷新）

| 参数 | 默认 | 说明 |
|---|---|---|
| `CANVAS_WIDTH` / `CANVAS_HEIGHT` | 640 / 448 | 画布尺寸 |
| `PIXEL_SIZE` | 8 | 像素矩阵每一格的放大倍数（小人、树、雪线格宽共用） |
| `PLAYER_SPEED` | 2 | 小人移动速度，单位是 **px/帧**（约 120 px/秒），与雪花的按秒计算是两套单位 |
| `SNOW_COLOR` | `#ffffff` | 空中雪花的最亮色 |
| `SNOW_GROUND_COLOR` | `#dde9f0` | 地面积雪 / 树上雪 / 小人头顶雪（哑光冷白） |
| `SNOW_EDGE_COLOR` | `#c8e4f5` | 积雪最上沿一格的淡蓝，做出厚度感 |
| `SNOW.SPAWN_Y` | −16 | 雪花出生高度（负值 = 画布上方之外） |
| `SNOW.SPAWN_MARGIN` | 32 | 出生点左右外扩，决定风能把雪吹进来多少 |
| `TREES` | 2 棵，scale 8 | 树的坐标与缩放，可自由增删 |
| `GRASS_BASE/LIGHT/DARK` | 三种绿 | 草地底色与草点深浅色 |

## 五、四个关键联动

**1. 同屏雪量 = 发射量 × 平均寿命**

```
60/秒 × 5.5s  = 330 片    默认，流畅
200/秒 × 5.5s = 1100 片
400/秒 × 15s  = 6000 片   必卡
```

**2. 落地耗时 vs 寿命**（从出生到落出 448px 高的画布）

```
默认（重力 20 / 初速 55）    4.60s   寿命上限 8s，够落地
重力 0 + 初速 30            15.47s   默认寿命下永远落不到地面，全在半空消失
重力 200 + 初速 305          1.11s   一眨眼就砸到底
```

**3. MIN / MAX 是区间端点，不保证大小关系**

`vy` 和 `life` 都按 `MIN + random × (MAX − MIN)` 取值。若把「慢」拉到比「快」还大，区间会反向——不报错，但两个滑块语义颠倒。建议始终保持 慢 ≤ 快、短 ≤ 长。

**4. 淡出时长 ≥ 寿命 → 一生都在变淡**

例如寿命 3/8、淡出时长 3：寿命短的雪几乎从出生就开始变淡，画面整体稀薄发灰。想要清晰的雪，淡出时长保持在寿命的 1/4 以内。

## 六、推荐预设

| 想要的效果 | 调法 |
|---|---|
| 默认柔和降雪 | 保持默认 |
| 暴风雪 | 发射量 200、重力 60、风力基准 60 + 幅度 80、寿命 4/8、上升 10 / 下降 14 |
| 静静飘雪 | 发射量 25、重力 8、自身飘动 40、风力基准 5 + 幅度 8、雪花大小 2 |
| 观察堆积滞后 | 堆积速度 0.05（默认），盯着 16s→22s 看雪地慢慢追上来 |
| 快速演示 | 上升 4 / 峰值 2 / 下降 5 / 晴天 6，一个周期 17 秒 |

## 七、URL 快捷演示

不改变正常玩法，仅用于**可复现的截图 / 演示**：

| URL | 效果 |
|---|---|
| `index.html?peak` | 跳过 78 秒周期，直接进入峰值（雪铺满、发射量翻倍） |
| `index.html?peak&warmup=250` | 在上面基础上，预生成 250 片雪花（截图用，无需等待飘落） |

刷新请强刷（`Ctrl + Shift + R`），浏览器会缓存 `index.html`。
